# 进化战争 · 第一关

用电脑的 Chrome 或 Edge 打开 `index.html`，点「进入战场」。游戏可离线运行。演练难度的补给和我方城门生命更宽裕，敌方城门生命更低。

第一关限时 2 分 10 秒，攻破敌方城门即获胜。开局由石器时代对青铜时代，30 秒后可花 54 补给抢先进化，51 秒后可免费进化。前三种基本兵可以直接招募，第四格需先花补给解锁。先用矛兵推进，再补远程和突袭。工事可在升代后继续使用。

| 操作 | 快捷键 |
|---|---|
| 招募，或首次解锁第四格 | `1` 至 `4` |
| 进化 | `E` |
| 城门工事 | `B` |
| 坚守号角 | `F` |
| 兵种训练与科技 | `T` |
| 暂停或继续 | `空格` |

首次获胜会保存战利金币。以至少四成的城门生命获胜可拿守关铜符，重玩时可带上守关重弩图纸。存档跟随浏览器和打开方式。

## 验证

- `npm test` 验证补给、首关单次升代、训练、工事、拦截、远程跨排与弹道结算、号角和胜负结算。
- 在 Chromium 标准难度重放两条路线。付费抢先进化用时 96 秒，先建投石台、再等免费升代用时 92 秒。纯远程到时未破城，纯突袭和无操作的对照局失守。
- 在 1440×900、844×390 和 740×360 的浏览器视口检查了布局。 [前一版桌面截图](调研/第一关-桌面实机.png) · [前一版横屏截图](调研/第一关-横屏实机.png)

## 美术

当前原型用 Canvas 绘制地形、城门、人物精灵与特效。人物关键帧由战斗状态驱动，按脚下位置排序，招募卡与战场共用图集。人物、地形和城门使用内置 ImageGen 制作的素材。

- 此仓库保留了上一版 3D 原型的 `models.js`、GLB 模型及许可文件。该版本采用 CC0 的 [KayKit Adventurers 2.0](https://kaylousberg.itch.io/kaykit-adventurers) 和 [KayKit Character Animations 1.1](https://kaylousberg.itch.io/kaykit-character-animations)，以及 MIT 授权的 Three.js。
