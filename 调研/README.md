# 进化战争 · 调研

整理日期为 2026 年 11 月 25 日。这里记录竞品证据和供讨论的设计方向。

当前玩法基线见 [10 首版玩法规则](10-首版玩法规则.md)。

## 已明确的方向

- 手机横屏，左右两端的基地通过同一条有宽度的道路交战。以《We Are Warriors!》的斜俯视镜头、错落站位和多人同屏交战为参照。
- 采用非像素画风。军队成团时仍然能辨认阵营、兵种和发生了什么。
- 能解锁兵种、提升攻防、升级基地防御，也给装备和圣遗物留下清楚的用途。
- 游戏主体是一场跨时代的大战役。单场可以简洁，多场战斗之间有地理、成长和战果上的联系。

## 当前最值得一起想的两件事

第一是镜头和材料感。参考游戏的道路纵深很大程度来自看得见的地面和接地阴影。我们可以把它保留，然后在「有实体质感的微缩战争」和「可活动的手绘插画」之间比较。两种都可以承载大兵群，画面气质和制作量不同。

第二是大战役里的时代和地理怎么相遇。一条连续推进的战线最容易让玩家理解。让几处关键地点跨时代再出现，则能给穿梭更鲜明的理由，也让同一张地图的改变值得看。

我的暂定倾向是**斜俯视的微缩战争 + 连续战役主线 + 少量可回访的跨时代地点**。微缩是比例和光影语言，具体偏木质、陶质还是偏手绘的表面仍有选择空间。战役先由地点与事件串起来，等回访有具体内容再决定要开放多大的时间地图。
